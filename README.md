# Edyta Kaczmarczyk — tłumacz przysięgły języka francuskiego

Strona wizytówka zbudowana w React, TypeScript i Vite.

## Uruchomienie lokalne

```bash
npm install
npm run dev
```

## Budowanie wersji produkcyjnej

```bash
npm run build
npm run preview
```

Treści i stawki przeniesiono z dostarczonych zrzutów DOM starej strony. Przed publikacją warto potwierdzić aktualność cennika.
